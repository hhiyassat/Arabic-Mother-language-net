## الأمثلة المُجمَّدة

### E01 — كَتَبَ الكاتبُ الرسالةَ (فعلية)

```
كَتَبَ    → فعل ماضٍ مبني على الفتح
الكاتبُ   → فاعل مرفوع وعلامة رفعه الضمة
الرسالةَ  → مفعول به منصوب وعلامة نصبه الفتحة
```

### E02 — عَلِمَ الطالبُ الحقيقةَ (فعلية)

```
عَلِمَ    → فعل ماضٍ مبني على الفتح
الطالبُ   → فاعل مرفوع
الحقيقةَ  → مفعول به منصوب
```

### E03 — مَكْتَب مكانُ كِتابةٍ (اسمية)

```
مَكْتَب         → مبتدأ مرفوع وعلامة رفعه الضمة
مكانُ كِتابةٍ  → خبر مرفوع وعلامة رفعه الضمة
```

### E04 — كَتَبَ الكاتبُ الرسالةَ في المكتب (فعلية + قيد)

```
كَتَبَ     → فعل ماضٍ مبني على الفتح
الكاتبُ    → فاعل مرفوع
الرسالةَ   → مفعول به منصوب
في المكتب → جار ومجرور — الاسم مجرور بحرف الجر (الكسرة)
```
